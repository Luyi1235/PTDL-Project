# PTDL 飞推控协同优化工作台

## 启动

### 在 PyCharm 中直接运行

用 PyCharm 打开本代码包，右键根目录中的 `启动_PTDL前端.py`，选择运行。启动后自动打开浏览器，控制台显示实际访问地址。默认端口为 8765，端口被占用时自动选择其他可用端口。文件使用自身位置定位模型和网页，工作目录可以保留 PyCharm 默认设置。

网页服务在 PyCharm 的运行进程中持续运行，点击停止按钮可关闭本次服务。优化计算优先使用当前解释器；依赖不齐时，自动检查本机已有科研 Python 环境。控制台分别显示网页服务与优化计算所用的解释器。

### 在 PowerShell 中运行

在 PowerShell 中运行：

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" ".\启动_PTDL前端.py"
```

程序自动打开工作台，访问地址以控制台输出为准。若本机没有上述 Python 环境，可使用已安装 `numpy`、`pandas`、`jsbsim` 的 Python 运行同一脚本。服务默认仅监听本机回环地址。设置环境变量 `PTDL_UI_OPEN_BROWSER=0` 可关闭自动打开浏览器。

2026-10-18 更新版当前运行于 `http://127.0.0.1:8770/`。当前会话保留原 8769 服务，使用 8770 访问本次更新。

## 可配置项目

- NSGA-II、MOEA/D、MOPSO、混合 NSGA-II/MOPSO、PTDL 耦合引导算法及种群分辨率、代数、随机种子。项目专用算法保留十六种子同预算比较中表现最好的耦合引导配置。
- MPC、分阶段 MPC、规则、模糊自适应、故障容错模糊及神经网络 MPC 模仿能量管理策略；MPC 预测步数、动作档位、SOC 权重及发动机功率平滑惩罚。
- 代理选项保留精细树组合模型和均匀覆盖组合模型，均使用 3072 个训练构型，默认选择精细树组合模型。两者均预测升力斜率与尾迹效率，并实际进入优化候选评价。右侧精度采用两批共 256 个留出构型的预计算复评结果，其中升力有效 248 个、尾迹有效 235 个。精细树模型的合并 MAE 为 0.01775、0.03381，R² 为 0.95092、0.85161。模型选择采用训练集交叉验证，两批留出构型用于复评，新的 192 构型独立评价仍在后台计算。02 气动范围提供代理模型、每个候选调用 VSPAERO、仅对 Pareto 候选调用 VSPAERO、逐积分步调用 VSPAERO 四种选项。
- 实算 VSPAERO 可选原始、中等加密和细网格，选择只影响真实求解路径。代理仍对应其训练时采用的网格设置。
- 响应目标可选恢复时间与扰动误差积分之和，或历史恢复时间与模式切换时间之和。结果图读取本次实际采用的定义，各算法共用坐标范围。
- 03 六自由度范围提供每个候选检查、仅对 Pareto 候选检查、将 JSBSim 作为逐积分步状态推进器，以及每候选完整任务闭环。
- 完整任务闭环可选“80 小时总任务（含下降和着陆）”或“先飞满 80 小时，再下降和着陆”；后者从 JSBSim 空中初始状态计时，不包括独立低阶地面起飞滑跑。
- 机翼和机身几何搜索范围。边界受所选 DOE 数据逐变量范围限制。
- 可展开查看或编辑 10 项基准机体参数；其中 7 项几何量作为优化器首个种子候选的初值，其余螺旋桨直径、任务载荷和混动系统质量也写入该种子。派生翼展、弦长、尾翼面积等随输入即时显示。
- 发动机/电机转速与额定倍率、发动机油耗倍率和功率变化率、电机并联支路、逆变效率、电池能量/内阻倍率与 SOC 限值。
- 动力高级参数可修改发动机基础功率、功率上限、混动质量功率增量、混动系统比能量、电机比功率、发动机效率曲线倍率及自定义燃油图 CSV 路径。组件初始化器额定值在同一处显示供参考。
- 迎风阶跃压力测试幅值和持续时间；六自由度候选筛查时长、JSBSim 积分步长，以及逐步 VSPAERO 的轨迹时长和积分步长。
- 运行时显示按优化代数和复评阶段更新的进度；完成后可按算法切换交互式三目标 Pareto 分布。
- 科研图集入口查看十组中文实验图，提供 PNG 和 PDF。

每次运行写入 `运行结果/前端运行_<时间戳>/`，包含有效配置、终端日志、优化档案、结果摘要及高保真复评文件。

工作台通过 `运行脚本/运行_工作台联合优化.py` 接入当前代理格式，再调用统一优化流程。该入口保持正在运行的科研计算所冻结的核心代码不变。精度发布脚本 `运行脚本/导出_工作台代理精度.py` 同时更新精度记录与页面内嵌数据。默认模型的精度表随页面直接显示，两款模型切换均读取页面内存，不请求精度接口，也不等待运行环境检查。新模型完成训练与评价后，运行发布脚本即可同步其显示值。旧模型和算法研究文件仍保留在代码包内。

Pareto 图展示正式优化目标 `J_energy`、`J_stability`、`J_response`，支持拖动旋转并悬停查看单个候选的目标值。燃油量、末端 SOC 等为诊断或工程筛选指标。DOE（试验设计）是预先选择构型样本点并进行 VSPAERO 计算，以训练气动代理模型；未收敛、非有限或响应超出适用范围的算例会记录但不纳入训练。DOE 点数本身不代表模型精度保证。“每个候选”表示优化器对每个设计调用一次相应检查；“逐积分步”表示使用当前状态更新模型并逐步推进，不是只在候选终点复评。

逐积分步 VSPAERO 会在每个优化候选的短时点质量轨迹上调用求解器，统计气动系数反馈给该候选的低阶任务评价；逐积分步 JSBSim 会按配置步长推进每个候选的短时六自由度响应，并将包线约束反馈给优化器。两者同时启用时，采用 VSPAERO 与 JSBSim 的同步联算器，每个 JSBSim 积分步调用一次 VSPAERO，升力/诱导阻力统计量和两类约束共同反馈候选评价；共享时长取两个设置中的较大值，共享步长取较小值。两者同时启用时共享仿真时长不得超过 10 秒。以上是短时候选级模型，不代表 80 小时任务全程以 VSPAERO/6-DoF 高保真积分。

运行按钮下方显示的预计时间根据当前算法数量、H、代数、控制器、积分步数，以及本机近期运行记录估算；尚无记录时使用回退基准。VSPAERO 每次调用耗时波动较大，因此同时给出范围，实际时间可能超出估算。

## 结果边界

VSPAERO 复评为候选构型气动计算，当前 CD0 为部件累加估计。短时六自由度选项运行候选短时检查，完整任务选项运行每个候选的 JSBSim 全任务并返回附加约束。当前三个正式目标仍由部件动力与纵向低阶任务计算。动力参数采用研究估计值。
