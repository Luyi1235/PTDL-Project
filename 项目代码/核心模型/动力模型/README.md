## 接入方式

PTDL 任务接口使用 kW、kg/s、秒和 0 至 1 的 SOC。源部件使用 W、V、A、N·m、rpm。电池放电为正，充电为负。飞推控闭环及 JSBSim 全任务向发动机传递实际高度。

发动机采用固定总成倍率缩放功率与燃油流量。电池按任务所需能量缩放等效并联容量，并反向缩放内阻。原始包内阻已经包含串并联换算，额外内阻倍率默认 1。电机支路数取用户设定的最小数量与满足总轴功率所需数量的较大值。总轴功率需要覆盖发电机及电池助推，页面上的助推功率倍率对应电池侧能力。

任务尺度电机输出使用负载轴功率 `P_shaft_W`，机械损耗和铜损保留在输入功率中。原生总成的动态求解器保留在 `full_system`。其 `propeller` 模块提供原生任务功率剖面，PTDL 飞行动力学仍使用本项目的螺旋桨需用功率与推力计算。

工作台的“动能学院三层能量管理”选项调用源 EMS 状态机，接收上一控制周期的发电、电池和电机实际功率。原有 MPC、规则、模糊及神经网络调度继续调用同一新版动力系统。MPC 预测中的发动机效率按当前高度从新版油耗图生成。

## 图谱适用范围

发动机图覆盖 0、3000、5000 m，2800、3900、5000、6100 rpm，以及 30 至 90 度节气门。转速超界在运行前报错。高度超界按源模型采用最近边界并累计记录次数。低于最小节气门功率时保留边界燃油流量，发动机停机时燃油流量为零。图谱文件未提供收敛标志，元数据中相应数量保持为空。

PTDL 现有总体额定倍率和能量估计继续保留。旧版油耗效率曲线不再覆盖源图燃油数据，历史 80 小时可行候选应使用新版重新评价。源模型在 5000 rpm、海平面最低节气门处的功率约 53.55 kW，低负载任务会受到该边界影响。
