- `核心模型`：评价函数、飞推控闭环、机体参数化、80 小时任务模型、混动调度、OpenVSP/VSPAERO 接口、气动代理模型、优化算法及 `Hybrid_System` 部件适配器。

- `核心模型/动力模型`：随包提供的发动机图/发电机、电池、电机和电力电子原始模型。
- `运行脚本`：优化、智能能量管理对比、多工况验证、全任务 JSBSim 闭环和典型工况控制策略比较入口。

- `气动代理模型数据`：VSPAERO 试验样本拟合得到的代理模型参数。
- `运行结果`：各运行脚本自动生成的结果文件夹。

### 方法组件与比较

发动机功率一阶响应使用连续状态空间 `xdot=(-x+K*u)/tau` 的零阶保持精确解；电机和迎角响应使用传递函数 `K/(tau*s+1)` 的精确离散解。通用多状态连续空间 `xdot=A*x+B*u` 另提供 RK4 推进。当前任务模型仍是非线性低阶方程与 JSBSim 六自由度的组合，不应将这些线性块表述为所有子系统都已完成显式状态空间建模或辨识。

2.2 的 PPT 三个正式优化目标不变。评价器在原有燃油能量与电池净化学能量核算基础上，新增电池充放电母线能量、转换损耗和能量管理效率诊断；该效率使用任务积分的充放电能量及配置的充/放电效率计算。电池能量损耗已通过净电池能量项进入正式能量目标，不另造第四个 Pareto 目标。无电池能量吞吐时效率诊断标记为无有效评估，避免将“未使用电池”误认为实测高效率。

纯无动力滑翔、地面起飞/着陆滑跑分别有筛查模块；地面滑跑现通过状态交接与 JSBSim 全任务和优化候选评价串接，但仍不是 JSBSim 地面动力学，也不应因模型能运行就记为工况通过。控制器典型工况对比、滑翔包线扫描、地面风扰动和多算法多随机种子入口均保留为独立可复跑流程。
