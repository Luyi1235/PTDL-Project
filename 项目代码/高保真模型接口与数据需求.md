# 高保真模型接口与数据需求

本文用于向动力、飞控和总体团队收集模型替换/验证输入。缺失数据可标记为“待提供”，不要用估算值冒充实测值。所有数据需附来源、单位、采样条件、版本和不确定度。

## 发动机与发电机

| 数据 | 单位/格式 | 必需说明 |
|---|---|---|
| 转速-扭矩-燃油流量图 | rpm、N·m、kg/h 或 g/kWh | 温度、海拔、燃油、稳态/瞬态条件 |
| 允许工作区和额定/连续功率 | rpm、kW、N·m | 连续与短时限制分别提供 |
| 启动、停机、怠速和负载阶跃响应 | s、rpm、kW、kg/h | 初始状态、指令、响应输出及采样频率 |
| 发电机效率/损耗图 | rpm、kW、% | 整流器/逆变器边界及热限制 |
| 燃油和热参数 | kg、°C、kW、J/K | 油箱可用量、热容量、温度限制及测点 |

| 质量和热参数 | kg、J/K、W/K、°C | 电机、逆变器、冷却系统分项 |

| 数据 | 单位/格式 | 必需说明 |
|---|---|---|
| 质量、重心、惯量张量 | kg、m、kg·m² | 随燃油/SOC/载荷的变化 |
| 气动数据 | 无量纲/度 | 力和力矩系数、构型、雷诺数、马赫数、失速与不确定度 |

| 验证时序 | 带时间戳的 CSV/HDF5 | 输入指令、传感器、发动机/电机/电池输出、状态和质量标记 |

## 数据交付约定

1. 每个文件附字段字典、单位、坐标系、时间基准和缺测值约定。
2. 标记数据类型：仿真、台架、地面试验或飞行实测；记录设备和校准信息。
3. 至少提供训练/辨识数据与独立验证工况，避免用同一批数据同时拟合和验收。
4. 给出有效域和超域处理方式；模型外推应返回告警或不可用状态。
5. 数据到齐后先做单位/能量守恒/边界检查，再辨识参数并与独立记录对比，最后接入 H=6 任务优化。

## 已实现的数据与仿真接口（2026-10-04）

- `核心模型/标定数据处理.py`：按 CSV 字段、来源类型、工况、单位声明、有限值和每个 `run_id/subsystem/signal` 的时间单调性检查输入；按完整试验 `run_id` 可重复划分训练/验证集。它不生成测量值，也不从参考模型伪造标定结果。
- `核心模型/ptdl_hil_protocol.py`：实现命令序号、执行器/功率范围、非有限数检查和通信超时归零逻辑。当前只到协议层，没有飞控接口板、总线驱动、实时调度或硬件保护回路。
- `运行脚本/运行_JSBSim六自由度参考冒烟测试.py`：以 JSBSim 自带 C172 参考机型验证六自由度运行时并导出状态时序。其参数与 PTDL 无关，不是 PTDL 六自由度验证。
- `运行脚本/运行_VSPAERO批量DOE.py`：批量执行已有待计算 DOE，并将求解成功标签与失败状态分开保存。只有运行后的 VSPAERO 极曲线是新增样本，Kriging 预测值不算新标签。

本机现已安装 OpenVSP 3.53.1 和 VSPAERO 7.2.2，并执行自适应 DOE 8 点：7 点得到有限极曲线，1 点全为 NaN 而拒收。该批求解观察到 `PGFace Invalid` 网格警告。7 个有限标签独立存放在 `运行结果/VSPAERO新增DOE实算_20261004/`，留一影响对照位于 `运行结果/VSPAERO新增样本留一影响_20261004/`。扩展候选集的升力斜率/Oswald 留一误差没有总体改善，所以正式 23 点样本和代理模型未更新。新增标签是低阶 VLM 的求解输出，不是风洞/飞行数据；经网格复核前不作为正式代理训练集。

## PTDL 专用六自由度估计模型（2026-10-04）

已新增 `高保真参考模型/PTDL_EST_6DOF/`、`核心模型/PTDL六自由度参考模型.py` 和 `运行脚本/运行_PTDL估计六自由度验证.py`。采用 DZYNE 2024 ULTRA 产品卡的翼展 24.9936 m、MTOW 1360.78 kg、油量约 613.24 L 作为历史构型量级锚点；当前 DZYNE 产品页与 AFRL 页面给出的续航/载荷指标属于其他版本或任务表述。36.011 m/s（70 kt）只是本项目选定的巡航参考工况，不是官方 ULTRA 巡航速度。PTDL 翼面积 26 m²、空重/载荷分配、惯量、三轴气动导数、舵面行程及执行机构时间常数均为工程估计。动力接口使用项目现有 80 kW 预估值和 0.86 螺旋桨效率换算推力，不代表发动机/电机实测响应。

60 s 三轴小幅输入验证使用 JSBSim 1.3.1、1/120 s 积分步长，输出 1201 个有限状态采样；质量闭合误差约 -0.00064 kg，姿态峰值约 17.66°，最低高度约 2944.53 m，最低空速约 32.47 m/s，软件冒烟包线通过。证据见 `运行结果/PTDL六自由度估计验证/`。

这项通过只说明估计 XML、单位转换、初始化、三轴舵面动态和数值积分链路可运行。气动/惯量/控制效能尚无可靠来源或独立验证，当前未接入 PTDL 优化器做六自由度闭环寻优；不构成动力标定、HIL、飞行性能或安全验证。用户已明确暂不开展 HIL 与飞行试验；真实动力标定仍待台架数据。

## VSPAERO 网格与 Oswald 效率口径复核（2026-10-06）

- VSPAERO 几何集合已分开：主翼、平尾、垂尾进入薄升力面集合；机身进入厚体/面元集合。几何生成和极曲线计算使用相同集合，避免将机身作为薄升力面参与 VLM。
- 对 DOE24、DOE31、DOE93 三个历史构型重新生成几何并实算。均生成 `.vspgeom`、`.polar` 和 CSV 极曲线；三次日志中 `PGFace Invalid` 与 `Faces have errors` 计数均为 0。该结果证明这三个构型通过本次几何检查，不代表整个设计域都已验证。
- 统一采用尾迹效率 `Ew` 作为优化/代理模型目标：取极曲线中 `|CLiw| >= 0.15` 点的 `Ew` 中位数；表面积分 `E` 只保留为诊断字段，不参与目标值。CSV 同时保存 `E`、`CLiw`、`CDiw`、`Ew`，便于追溯。常规极曲线尾迹迭代数为 30；逐积分步接口仍用 10 次以控制单步运行耗时。
- doe24 本次 `Ew=0.8118`，其表面积分 `E` 含负值及明显异常值，说明两列不能互换。doe31、doe93 的本次 `Ew` 分别约为 0.8170、0.5730。
- 历史 DOE、旧代理模型及旧交叉验证文件均未覆盖；它们仍属于旧效率标签口径，不能与新 `Ew` 标签混合训练。现有 23 点源数据缺少 `Ew` 定义元数据，因此 40/100 点 `Ew` 重训脚本会拒绝旧源数据，待 23 点重算或另建完整 Ew 数据集后再训练。
